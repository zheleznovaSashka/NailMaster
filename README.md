# 💅 Nail Master

Сайт мастера маникюра на Django.

## 🎯 Возможности

- 🏠 Главная страница с информацией о мастере
- 🖼️ Портфолио работ
- 📚 Онлайн-курсы с видео
- 🛒 Корзина покупок
- 📦 Заказы и их отмена
- ⭐ Отзывы с модерацией
- 📸 Скрины отзывов с других площадок
- 📞 Контакты и онлайн-запись
- 👤 Профиль пользователя
- 🔐 Восстановление пароля
- 🎛️ Панель управления для мастера

## 🛠️ Технологии

- Django 6.1
- Bootstrap 5
- SQLite (для разработки)
- MS SQL Server (для продакшена)
- Pillow (для работы с изображениями)
